Kivi

قاعدة البيانات التي تُبرِز إيصالاتها · v1.1.0 · الصيغة v2

قاعدة بيانات بنمط سجلّ الأحداث مكتوبة بلغة Go خالصة — ملفٌّ تنفيذيٌّ ساكنٌ واحد قادرٌ على تعليل كل إجابةٍ يقدّمها.

## ما هي Kivi

تُخزِّن Kivi **الأحداث** فقط — سجلّاتٌ غير قابلة للتغيير ومترابطةٌ بسلسلة تجزئة. وكل ما يبدو كحالةٍ راهنة (جدول، أو رسم بياني، أو سلسلة زمنية، أو فهرس متجهات) هو **عرض**: طَيٌّ فوق تلك الأحداث، يُعاد تجميعه عند الطلب وقابلٌ للإسقاط في أي لحظة. تحمل كل إجابة **أثرًا** (أرقام السجلّات التي أثبتتها) و**نطاقًا** (إلى أي مدى نظرت في التاريخ)، ويعيد `why` سجلّات الإيصال نفسها. البيانات الغائبة رفضٌ صادق، لا اختلاقٌ أبدًا.

## المبادئ الثلاثة

**الأحداث وحدها دائمة.**  
لا وجود لـ UPDATE. تُلحَق الوقائع الجديدة؛ ولا يُعاد كتابة الماضي أبدًا. التاريخ مواطنٌ من الدرجة الأولى.

**التمثيلات مُجمَّعة.**  
حذف `derived/` مشروعٌ دائمًا: لا تتغيّر الإجابات، بل يصبح الاستعلام التالي أبطأ فحسب.

**لا إجابة بلا أثر.**  
الإجابة بلا أثر غير قابلة للتمثيل — في النواة وفي كل SDK. لا شيء يُختلَق.

## فيمَ تختلف عن قاعدة بيانات عادية

|  | قاعدة بيانات نمطية | Kivi |
| --- | --- | --- |
| ما هو الدائم | الحالة الراهنة؛ وUPDATE يُدمّر الماضي | الأحداث؛ والحالة يُعاد تجميعها منها |
| الإجابات | قيمٌ عارية | قيمة + أثر + نطاق؛ و`why` يجلب الإيصالات |
| نقطة زمنية | لقطاتٌ وآليّاتٌ إضافية | مجانيٌّ بحكم التصميم: اطوِ حتى السجلّ N (`--as-of`) |
| السلامة | مُفترَضة | مُتحقَّق منها: سلسلة SHA-256 + أختام Ed25519؛ والعملاء يعيدون التحقّق من الخادم |
| الحذف | ذهب الصفّ، وذهبت الحكاية | محوٌ تشفيري: يُدمَّر المفتاح، وتبقى البايتات كما هي، ويُوثَّق المحو بإيصال |

## بداية سريعة

شغِّل الخادم (ملفٌّ تنفيذيٌّ ساكنٌ واحد، أو صورة حاوية):

```
# Docker
docker run -p 4741:4741 -p 4742:4742 -e KIVI_TOKEN=change-me iwasoftcom/kivi:1.1.0

# or the binary
KIVI_DATA=/var/lib/kivi/kivi.ledger KIVI_TOKEN=change-me kivid
```

ألحِق حدثًا واقرأه ثانيةً — تأتي الإجابة مصحوبةً بأثرها:

```
kivi append ./kivi.ledger property '{"subject":"dog","attribute":"sound","value":"woof"}'
kivi table  ./kivi.ledger dog sound
# → {"scope":0,"trace":[0],"value":"woof"}

kivi verify ./kivi.ledger        # re-hash the chain, check every seal
kivi why    ./kivi.ledger 0      # the receipt behind the answer
```

يتحدّث العملاء العقدَ نفسه في **ست لغات** — Go وPython وJava & Kotlin وRust وNode.js و.NET — بوصولٍ مُنمَّط «كائنٌ داخل، كائنٌ خارج»، مع تفعيل التحقّق في جهة العميل افتراضيًّا.

## ماذا بداخلها

**إجابات ذات أثر**  
كل قيمة تستشهد بالأحداث التي أثبتتها؛ ولا يمكن بناء إجابةٍ بلا أثر.

**السفر عبر الزمن**  
«ماذا كنّا نعرف عند السجلّ N؟» إعادة تشغيلٍ واحدةٌ محدودة — بلا لقطات، بلا ترحيلات (`--as-of`).

**سلامةٌ مُتحقَّق منها**  
سلسلة تجزئة SHA-256 + أختام Ed25519؛ حتى بايتٌ واحدٌ مُبدَّل يُكتشَف ويُسمّى.

**محوٌ تشفيري**  
مفتاحٌ لكل سجلّ؛ المحو يُدمّر المفتاح، ويُبقي السلسلة صحيحة، ويوثّق المحو نفسه.

**ACID بصيغة الإلحاق فقط**  
ذرّيةٌ لكل حدث، وكتاباتٌ متسلسلة، وقراءاتٌ من لقطة، ومتانةُ `fsync` بالتزام جماعي.

**عنقودٌ واتحاد**  
تحوّلٌ عند العطل بالتزام الأغلبية، ونُسخ قراءة، وشهادةٌ متبادلة بين سجلّاتٍ مستقلة.

**لوحة إدارة وهوية**  
واجهةٌ مُضمَّنة، وتهيئةٌ موثَّقة بإيصال، ومستخدمون/أدوار/جلسات، ومفاتيح API مُسمّاةٌ وقابلةٌ للإبطال.

**بابُ نماذج اللغة (MCP)**  
يمنح وكيلَ ذكاءٍ اصطناعيٍّ ذاكرةً تستشهد بمصادرها؛ والحقيقة الغائبة تُرفَض لا تُهلوَس.

**متعدّد المستأجرين عند الطلب**  
عدّة مستأجرين معزولين في عمليةٍ واحدة — ويمكن فتح مستأجرٍ جديد أثناء التشغيل عبر واجهة الإدارة، بإيصالٍ ودون إعادة تشغيل.

**يعمل كخدمة**  
systemd على لينكس (.deb/.rpm)، وخدمة Windows حقيقية من المُثبِّت — يبدأ مع الإقلاع ويُفرِّغ بسلاسة عند الإيقاف.

## لوحة الإدارة

يأتي كل خادم بلوحة ويب مُضمَّنة (دون نشرٍ منفصل) على منفذ الـ ops. افتح `https://<host>:4742/admin/` وسجّل الدخول بحساب مستخدم — ومن هناك، مباشرةً ودون المساس بمستوى البيانات، يمكنك:

-   **نظرة عامة والفترات** — الصحة، وأعداد السجلّات والأختام، والتدوير.
-   **السجلّات والبحث** — بثٌّ حيٌّ للإلحاقات، إضافةً إلى البحث الدلالي.
-   **العنقود والاتحاد** — الطوبولوجيا، وحالة التحوّل عند العطل والشهادة.
-   **المستخدمون ومفاتيح API** — إنشاء الحسابات والأدوار، وإصدار المفاتيح وإبطالها.
-   **الإعدادات** — إعادة ضبط الحدود والإعدادات؛ وكل تغييرٍ يُوثَّق بإيصالٍ في السجلّ (الأسرار لا تُوثَّق أبدًا).

## البنية

عمليةٌ واحدة، وبابان شبكيّان، وقاعدة اعتماديّةٍ صارمة: النواة تستخدم مكتبة Go القياسية وحدها؛ وgRPC يعيش عند الحافة. على القرص توجد حقيقةٌ دائمةٌ من نوعٍ واحدٍ بالضبط — سجلّ الأحداث — وكل ما عداه قابلٌ للإسقاط.

CLI · حزم SDK بست لغات لا يثق: يتحقّق في جهة العميل لوحة الإدارة · وكلاء LLM ‏(MCP) واجهة مُضمَّنة · ذاكرةٌ تستشهد مستوى بيانات gRPC · ‏:4741 ops HTTP · ‏:4742 النواة ‏(Go stdlib)‏: سجلّ · عروض · أثر · ختم · هوية الإجابات تُجمَّع وقت الاستعلام — لا شيء مُشتَقٌّ يُعدّ أصليًّا القرص: سجلّ أحداث بالإلحاق فقط (+ أختام)

### العميل الذي لا يثق

كل حزمة SDK تكشف نفس السطح الصغير المُنمَّط — والتحقق من جهة العميل **مُفعَّل افتراضياً**: يعيد العميل حساب تجزئة السلسلة ويتفقّد أختام Ed25519 أثناء القراءة، فأيّ خادم كاذب أو بايت واحد مقلوب يُكتشَف، لا يُوثَق به.

-   `append(type, body)` — أضِف حدثاً، واحصل على إيصاله.
-   `table(subject, attribute)` — **إجابة مُتتبَّعة**: `value` + `trace` (أرقام السِّجِلّات التي أثبتتها) + `scope`. الخليّة المفقودة هي رفض صادق — استثناء أصلي في اللغة، لا قيمة null مُلفَّقة.
-   `table(…, as_of=N)` — نفس الإجابة **حتى السِّجِلّ N** (السفر عبر الزمن).
-   `why(trace)` — سِجِلّات الإيصال نفسها.
-   `replay()` — بثّ كل سِجِلّ، مُعاد التحقق منه من جهة العميل.
-   `similar(query, k)` — بحث دلالي مُتتبَّع (سِجِلّ + درجة).
-   `login(user, pw)` — رمز جلسة محدود بالدور؛ `with_bearer` يعيد استخدام القناة تحت هويّة أخرى.
-   `head()` — توجيه رخيص (رقم الرأس + التجزئة)، دون تدقيق.

### مثال (Python)

الشكل متطابق في اللغات الستّ جميعها:

```
from kivi import KiviClient

c = KiviClient("localhost:4741", token="…")     # verify=True by default
c.append("property", {"subject": "dog", "attribute": "sound", "value": "bark"})
a = c.table("dog", "sound")              # TracedAnswer(value="bark", trace=[0], scope=0)
old = c.table("dog", "sound", as_of=41)  # the answer as of record 41
receipts = c.why(a.trace)                # the actual ledger records
for rec in c.replay():                   # hash + chain + seal verified CLIENT-SIDE
    ...
```

اختبار مطابقة واحد يُشغَّل على اللغات الستّ جميعها، فتُعيد كل لغة الإجابة ذاتها بالأثر ذاته. أمثلة كل لغة (Go وJava / Kotlin وRust وNode.js و.NET) وطبقة الكيانات المُنمَّطة موجودة في [المرجع الكامل](reference.en.html).
